# AutoPro Rīga 🚗🔧

Profesionāla autoservisa mājaslapa ar vizīšu pieteikšanas sistēmu.

## Features

- **Responsive Design** — works on desktop, tablet, and mobile
- **Booking Form** — full appointment booking with service selection, date/time picker
- **Services Showcase** — 6 service cards with pricing and quick-book buttons
- **Quick Services Bar** — floating cards for popular fast services (oil change, brakes, A/C, battery)
- **Customer Reviews** — testimonial section with star ratings
- **Contact Section** — address, phone, email + embedded Google Maps
- **Success Modal** — confirmation popup after form submission
- **Smooth Scrolling** — anchor navigation with scroll animations
- **Mobile Nav** — hamburger menu for small screens

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Inter)
- Font Awesome 6 icons
- Google Maps Embed

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/ojayWillow/autopro-riga.git
   ```
2. Open `index.html` in your browser — that's it!

## Customization

- **Contact info**: Update phone, email, and address in the Contact section and footer
- **Prices**: Edit service card pricing in the Services and Quick Services sections
- **Google Maps**: Replace the iframe `src` with your actual location embed URL
- **Colors**: Modify CSS variables in `:root` at the top of the `<style>` block
- **Logo**: Change the text in the `.logo` element or replace with an image
